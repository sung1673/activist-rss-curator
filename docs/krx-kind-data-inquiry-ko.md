# KRX KIND 공시 데이터 이용 문의 초안

수신: `krxdata@krx.co.kr`

제목: KIND 공시·시장조치 역사/증분 데이터 및 공개 서비스 이용 범위 문의

안녕하세요.

BSIDE는 한국 상장회사의 거버넌스 사건을 공시, 당사자 입장, 보도, 결과와 후속 이행까지 연결하는 공개 기록 서비스를 준비하고 있습니다. 매수·매도 권고나 목표가를 제공하지 않으며, 공시의 원문 제목·회사·접수시각·접수번호·원문 링크와 이를 바탕으로 확인한 사실·상태를 제공하려고 합니다.

KRX KIND 공시 및 시장조치 데이터와 관련해 아래 사항을 문의드립니다.

1. 2021년 1월 1일 이후 역사 데이터와 향후 증분 데이터를 받을 수 있는 상품·계약·전달 방식
2. 제공 가능한 필드: KIND 접수번호, 종목코드, 회사 식별자, 회사명, 시장, 접수시각, 원문 제목, 공시 유형, 정정·취소 관계, 원문 URL
3. 거래정지·상장적격성 실질심사·상장폐지 관련 시장조치의 포함 여부
4. 내부 데이터베이스 저장, 중복 제거, 회사 식별자 결합, 사건 분류와 내부 AI 분석의 허용 범위
5. 공개 웹·RSS·CSV·JSON API에서 사실·메타데이터·원문 링크를 제공할 수 있는 범위와 필요한 출처 표시
6. 원문 전문·첨부파일은 재배포하지 않고 KIND 원문으로 연결하는 방식의 허용 여부
7. 데이터 수정·삭제·정정 통지를 수신하거나 동기화할 수 있는 방법
8. 예상 비용, 심사 절차, 이용기간, 갱신·철회 조건과 기술 담당 문의 창구

가능하다면 데이터 사양서, 샘플 레코드, 이용약관과 신청서를 함께 안내 부탁드립니다.
